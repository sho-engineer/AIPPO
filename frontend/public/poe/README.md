# ポーの画像

AIチューター「ポー」の表示状態。このディレクトリに6枚を配置する。

```
neutral.webp    通常の説明、待機
question.webp   ユーザーへの質問
thinking.webp   AI処理中
hint.webp       ヒントや改善案
warning.webp    個人情報、誤情報などへの注意
celebrate.webp  課題完了
```

## 要件（AIPPO 開発概要 §7）

- 背景透過
- 同じサイズ（512×512px）
- 同じ位置・構図
- WebP または PNG
- 初期は静止画
- CSS で軽い上下移動や跳ねる動きを追加してよい

**Live2D / 3D / 音声 / 口パクは MVP に含めない。**

## 作り方

基本デザインを1枚確定させてから、**その画像を編集して表情だけを変える**。
毎回ゼロから生成すると別キャラクターになりやすい。

デザインの方向性:

- 20〜40代の会社員が使っても子どもっぽくない
- 人間でも完全なロボットでもない
- 丸みのある小さなナビゲーター
- シンプルな服装
- 特定のAI企業を連想させない
- アプリ右下に表示しても判別できる

ポーの性格とレッスンでの使い方は
[`docs/ai-tutor-design.md`](../../../docs/ai-tutor-design.md) を参照。

画像が未配置でもアプリは動作する（`alt` テキストが表示される）。
