# P0 / P1 / P2

報告するときは、必ずこの3段で分ける。**「軽微」「重大」と書かない**
——読む人によって幅が変わる。

---

## P0 — 出せない

1つでもあれば公開しない。

- Lesson を開始できない
- Lesson を完了できない
- AI 生成が機能しない
- データ消失
- **未公開 Lesson へアクセスできる**
- 認証・権限の問題
- 本番 Build が通らない
- 主要導線が完全に停止

---

## P1 — 学習が止まる

リリースを阻害するものは0件にする。残すなら、**残す理由を書く**。

- CTA が Viewport の外
- Back / Close の不具合
- 不要な Scroll
- Layout Shift
- Text Flash
- 診断結果の矛盾（現在地と次の一歩が食い違う、など）
- AI 出力の品質が学習を阻害する
- 小さい iPhone で主要操作ができない
- Recommendation と公開状態の不整合（準備中の Lesson を勧める）

---

## P2 — 直したいが、止まらない

公開してよい。次の機会に直す。

- 軽微な余白
- 表現の改善
- 小さなデザインの不統一
- 操作を阻害しない視覚上の問題

---

## 書き方

```
P1: Pixel 5（393×727）の完了画面が 9px 送れる
    原因: 「仕事で使う形」を出す高さの境目が 700px で、
          700 と 727 のあいだに端末が挟まっていた
    対応: 境目を 780px へ。札は記録の一枚に残る
```

**何が起きたか / なぜ / どうしたか** の3つを書く。
直していないなら「未対応」と書く——直したことにしない。
