# UI / Content Rule

iPhone Safari を最優先。学習者は AI初心者の会社員。

---

## 画面

| 決まり | なぜ |
|---|---|
| 1 Screen = 1 Action | 押す場所が2つあると、どちらが本筋か決められない |
| 原則 No Scroll | 送らないと押せない画面は、押す場所が無いのと同じ |
| Card 内 Scroll 禁止 | 外側が動かないので、送れることに気づけない |
| Layout Shift 禁止 | 押そうとしたものが動く |
| Text Flash 禁止 | 一瞬だけ違う文字が出ると、読み直しが要る |
| CTA の位置を画面間でそろえる | 指を同じ場所に置いたまま進める |
| Safe Area 対応 | ホームバーに重なると押せない |
| Back は直前の状態へ | 開いた一枚があるなら、まずそれを閉じる |
| Close は Lesson を開いた元の画面へ | どこから来たかは人によって違う |

長い文章は **Preview ＋「全文を見る」**。画面に全文を積まない。

ボタンを押して UI 全体が下へ押し出されない。出し入れするものは、
出る前から場所を取っておく。

## 部品

- **既存 Component を最大限再利用する**
- Lesson ごとの独自UIを乱造しない
- **Canonical Po を再デザインしない。** Po の絵を AI で作り直さない
- 音は Enhancement。Lesson の進行を音に依存させない
- 音だけで状態を伝えない。動きだけで状態を伝えない

---

## Compare の順

```
何を変えた？ → どう変わった？ → 代表例 → （必要なときだけ）全文比較
```

全文の読み比べを既定にしない。202字と202字を毎回突き合わせると、
**いちばん見てほしい変化がその中に埋もれる**。

## 画像

使うのは、**理解が速くなるときだけ**。

| 種類 | 使いどころ |
|---|---|
| Lesson Overview | その日つくるものを1枚で見せる |
| Section Intro | 段が変わったことを伝える |
| AI技 Concept Visual | 言葉だけでは伝わらない概念 |
| Compare Visual | UI では見せにくい変化 |
| Completion / Reward | 終わりを祝う |

### 決まり

- 1画像 = 1 Visual
- **UI で出せる文字を、画像へ大量に焼き込まない**
- **CTA を画像へ焼き込まない**（押せるものは Component で持つ）
- Header と画像内で同じタイトルを重複させない
- ロゴ・Lesson名・Section名・タイトル・説明・Po・CTA を1枚へ詰め込まない
- **情報が増えるだけなら作らない**
- 比較が UI で伝わるなら Compare 画像を作らない

**作らないと決めたことも Spec に記録する**（`assets` を `null` にする）。
記録が無いと、次に触る人が「作り忘れ」と読む。

## 動き（Motion）

使うのは、**理解か、画面が切り替わったことの把握に要るときだけ**。

| 決まり |
|---|
| 原則 300ms 以内 |
| Loop 禁止 |
| 点滅・発光・Particle 禁止 |
| 操作を待たせない |
| **CTA を動かさない** |
| Layout Shift を起こさない |
| `prefers-reduced-motion` に対応する |

### 使ってよいもの

**Section Intro のコンテンツ領域だけ**、短い Fade + translateY。

```
opacity 0 → 1 / translateY 8px → 0 / 300ms / ease-out / 1回だけ
```

実装は `animate-section-intro`（`tailwind.config.js`）。動かすのは絵の
層だけで、Header・Close・CTA・タップ層は**外に置く**
（`SectionTransition.tsx`）。押せるものが動きながら出てくると、
出た瞬間に押した指が空振りする。

`prefers-reduced-motion` は `src/index.css` の共通ルールが 0.01ms まで
詰める。`animation: none` にしないのは、遅らせて出す要素が現れない
まま消えるため。

### 使わないもの

- AI 処理をしていないのに、待ち時間を作る演出
- 診断の「分析しています」のような、選択肢に見えるカードが順に埋まる画面
  （**自分が押していない項目にチェックが付く**ように見えた）
- Po の浮遊・拡大縮小
- 星・音符・光の個別アニメーション
- Parallax / Bounce / 連続 Loop
- CTA の遅延表示・移動
- 画像の大きな Scale
- 画面全体の Fade
- Section 遷移時の白画面
