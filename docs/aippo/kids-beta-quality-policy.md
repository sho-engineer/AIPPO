# Kids 検証運用（AIPPO-018）

CEO指示（2026-10-16 MYT）：通常の変更はcriticalな検証を実施し、全ライフサイクルはβリリース前に実行する。

## 通常の変更

- TypeScript、Lint、教材仕様検査、Build、変更に関連する単体テスト。
- 記録の消失・誤帰属、認証とアカウント混同、学習開始/完了不能、誤った昇格/解放をcriticalに含める。
- 今回は旧schema1/2/3→stable ID、スタンプ重複防止、スタンプ不足/テスト不合格/両条件達成、最小縦横のホーム/ページ後半/テストの到達を確認する。
- 全24模擬ペルソナから批判を集め、採否理由を残す。実親子評価とは区別する。
- CIはcritical Kids、タイトル/動画、認証/公開制御と実backend smokeを実行。未実施の全ライフサイクルをPassedとはしない。

## βリリース前

GitHub ActionsのCIを `workflow_dispatch`、`full_lifecycle=true` で起動する。通常省略する既存の全Kidsライフサイクル、全viewport/回転、全core E2Eを含める。タイトルの40検証も別ジョブで実行する。ケースの削除やテスト条件の緩和で全成功にしない。

この手順は実行機能の用意であり、βの全検証が完了したという意味ではない。実行したcommit・件数・失敗/未実施と証跡を台帳へ記録し、未解決P0/P1がある場合は公開しない。

実機Safari、実親子の読解/楽しさ/教育効果は別の未確認項目。大人向けLesson catalogの公開状態、Canonical Po、安全説明は変更しない。
