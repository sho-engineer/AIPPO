# Workへ渡す指示｜AIPPO Kids 森ワールド Stage1 最終実装

**最初に `docs/STAGE01_FINAL_SPEC_JA.md` を全文読み、そこを最新版の正として扱ってください。**

このファイルは Stage1 の最終合意に基づく独立パッケージです。以前のStage1〜5用ZIPのStage1内容は古いため、これを優先してください。**今回の実装対象はStage1に限定**し、Stage2以降の細部を承認済みとして確定しないこと。

作業：
1. 既存リポジトリ／コード構成／UIコンポーネント／状態保存／マップを調査し、Stage1の導入→3ラウンド→完了→スタンプを実装／改修。
2. 既存キャラの参照造形と本番寄りUIを維持。生成UI参考画像の装飾をむやみに模倣せず、モバイル実機でノースクロール・ボタン視認性・固定レイアウトを保証。
3. 最優先で **2D設計図をパーツ合成する描画エンジン**を用意。子どもの入力に対応する構造化命令→検証→状態変更→実際の結果表示→確認→必要なら再試行。未対応の依頼を適当に成功扱いしない。
4. R1「自分で対象＋成果物を選択」、R2「大窓を追加」、R3「月の石を入れる場所を自分で考えて追加」。元の設計内容を継承。
5. カードで確実に遊べる初期実装とし、将来の音声認識・GPT解釈の差し替え口は設計するが、現時点で実際の外部AIや子どもの音声を無断送信しない。
6. ポーちゃんの順次吹き出し、読み上げ対応、表情変化、パーツ出現アニメ（軽量）を実装。年齢別難易度とヒントの扱い、再開・保存を確認。
7. 確認が必要な素材、実装済み／未実装項目を区別し、実際の画面キャプチャとQA報告をまとめる。**ユーザーの許可なく本番公開しない。**

**最重要の受け入れ条件：子どもがお願いした内容と表示された結果の不一致をスルーして成功扱いすることは絶対に禁止。表示・確認の工程を飛ばさない。**
