# AIPPO：製品方針の正本

更新：2026-10-24。Claude / Codex / Command Centre 共通の企画判断の入口。
この文書は既存のKidsへの方針変更を明文化するもので、新しい対象への再転換ではない。

## 現在の優先対象とゴール

現在の開発・β検証の重点は **AIPPO Kids**。2026-10-12以降に合意した「5歳から段階的に、個人別の進度で学ぶ」を引き継ぐ。

目指すのは、子どもが自分の目的を伝え、AIの答えを確かめ、必要なら直し、安全に使う／使わない判断を練習できること。
子ども向けの一言は「AIに つたえる。たしかめる。じぶんで なおす。」。
日常の未練習の目的に使えることは目標であり、ステージ完走だけで達成認定しない。

- 5〜6歳：保護者の読む援助を前提に、カード選択等から始める。単独利用を約束しない。
- 7〜9歳：同じ基礎を自分で判断する場面を増やす。
- 10〜12歳：目的・比較・理由を深く考える入口を持つ。年齢別カリキュラム一式や自由入力教材の完成を意味しない。
- 年齢は案内の初期値。理解・読字・経験を年齢だけで固定せず、深さを切り替えられる。

保護者には、実践課題でどの操作・判断を確認できたか、どの援助が必要だったかを示す。スタンプ・ピラミッド・記録は課題内の証拠であり、IQ・他児との優劣・教育効果の認定ではない。

## 大人版との関係

AIPPOは当初、AI初心者の会社員向けに開発された。現在のKids集中は意図した優先順位であり、大人向けLessonの追加をKids βの前提にしない。
既存の大人版・教材・認証・記録の資産は維持する。廃止・削除・Kidsへのデータ統合は決定していない。再拡充やB2B展開の時期は別途事業判断とする。
READMEの大人向け技術説明やLessonの公開規則を、Kidsの企画方針と混同しない。一方でKids変更による大人版・共通基盤の回帰は検査する。

## Kidsの体験・正本

冒険で基礎を練習 → 理解と実践のミニテスト → スタンプ／次の段階 → 日常チャレンジ・任意のおうちミッションへつなぐ。
5つの基礎は、具体的に伝える・比較修正・複数条件・目的に合う創造・安全な判断。実践をクリック数や途中正解で代替しない。

| 範囲 | 正本と境界 |
|---|---|
| 企画・対象・優先順位 | この文書 |
| Kidsの画面・課題・状態・採点 | `frontend/src/kids/learning.html` |
| standalone | `frontend/public/kids-title/index.html` は生成物。frontendで `node scripts/build-kids-title.mjs` により同期 |
| Kidsの検証 | [kids-beta-quality-policy.md](kids-beta-quality-policy.md)、実際のCI・回帰テスト |
| 大人向けLesson | 本ディレクトリのLesson制作・公開規則、およびcatalog→seed→DBの3層 |

実際の課題数・UI文言・対応状態は最新コードを確認する。古い引き継ぎの固定件数やcommitを最新仕様として使わない。

## 体験上の条件と初期βで増やさないもの

- スマホ／iPadを想定し、文字・ルビ・理由・ボタンが最小縦横画面で欠けず、選択時に操作位置が動かないこと。
- ひらがな／読み仮名による読字支援をデフォルトとし、設定保存と適用状態を伝える。
- PoとAIPPOらしいゲーム感、入口と退出、物語からマップ、結果から次の目的までを一続きにする。
- Canonical Poを再デザインしない。音声追加は不要、絵文字を多用しない。短い演出とreduced-motion対応を守る。
- 初期βは無料・限定的な基礎体験。有料化、同期、複数児管理、自由AI会話、音声、ランキング、大量ステージ追加を公開前提にしない。
- Kidsの教材内シミュレーションと実AI利用を区別する。外部AI利用は保護者の任意の手動操作であり、子どもの自由な外部送信を前提にしない。
- Kids記録は現状端末内の単一プロフィール。任意保護者ログインをKidsの同期保証と説明しない。大人版のアカウント引き継ぎ仕様をKidsへ流用しない。
- 家庭での実行・記録・作品提出を進級条件にせず、模擬課題で実物や完成作品を作ったと誤って約束しない。

## 「完成」の判定を分ける

**実装・マージ**：対象commitの必要な検査が成功し、未解決P0/P1がなく、入口→課題→結果→退出、設定復帰、保存・移行・誤帰属・重複昇格の主要経路が成立する。検証範囲はKids検証運用に従う。

**限定βの試用準備**：β前の全ライフサイクル検査と対象実機の入口・操作を確認し、対象・保存制限・シミュレーション・援助条件を案内する。実行したcommit、成功／失敗／未確認を記録する。CI成功だけで実親子評価を済ませたとはしない。

**価値・学習・商用版**：実親子の理解、楽しさ、援助、別条件への応用、継続、親の価値、課金意向を別途確かめる。完走・スタンプ・AI模擬レビューだけで効果や有料継続の成立を認定しない。

24ペルソナはAI模擬。各IDの批判・根拠・反論・採否・副作用・未確認を記録し、重大な少数意見を多数決で消さない。実際の参加者24人や実親子テストと報告しない。

## 企画検証案と未決定事項

Command Centreでは、無料・6家庭（5〜6歳／7〜9歳各3）・7日間・依頼合計約25分／上限30分、最初の2家庭から残り4家庭へ進める案をまとめた。初回は最初のロケット課題、後日は体験済みの技能に対応した未練習条件で確認する。未到達の比較・修正・安全を習得済みとしない。
これは**実施前の運用案**であり、募集済み・参加承諾済み・実施済みではない。対象家庭・日程・最初の立ち会い可否はユーザーが判断する。観察手順を変更した版の結果を無条件に合算しない。
有料版の価格・範囲・開始時期、大人版の再拡充時期も未決定。これらをAIが既決事項として補完しない。
