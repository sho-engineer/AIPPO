### MVPの完成条件

以下まで動けば、最初の実証実験に使える。

- [x] キャラクター1体 — ポー
- [x] 表情6枚 — `frontend/public/poe/*.webp` と `frontend/public/assets/po/*.webp`
      （**仮画像**。正式画像に差し替える）
- [x] 吹き出し — `aria-live="polite"`
- [x] レッスン — 教材9本（成果物ファーストの19ステップ）。
      第一リリースで開くのは `diagnosis` と `rewrite_text` の2本
- [x] 穴埋め入力 — `StepViews`（誰向け・どんな表現・どれくらいの長さ）
- [x] AI実行 — `POST /api/v1/ai/generate/`
- [x] 1回の改善 — 条件を足して比べる（`ChangePoints` / 3つ比べ）
- [x] 自分の文章で再実行 — `real_task` ステップ
- [x] 完了画面 — `CompletionView`
- [x] 操作ログ — `POST /api/learning-events/`（本文は送らない）

Live2D / 音声 / 口パク / 3D / 複数キャラクターは不要。
最初は「キャラクターがかわいいか」よりも、
**初心者が次に何をすればよいか迷わないか** を検証するのが優先。

### 第一リリース（クローズドベータ）で足したもの

- 教材を DB へ移し、Django Admin から編集できるようにした（`backend/apps/catalog`）
- 公開する教材を絞る仕組み（`available` / `coming_soon`）
- 登録・ログインと、ゲストの記録の引き継ぎ（`backend/apps/accounts`）
- Google と LINE でのログイン（`accounts/social.py` / `social_signin.py`）。
  鍵を入れた先だけボタンが出る
- 端末をまたいだ進み具合（`GET /api/v1/progress/`）
- 利用規約・プライバシーポリシー・AI利用上の注意（アプリ内で読ませる）
- 認証の連打を止める仕組み、古い記録を消す仕組み
- メール3通、`/health/live` と `/health/ready`

### いま残っていること

コード側で残っているもの。

- **ポーの正式画像**。6枚とも仮画像のまま。差し替え口は
  `frontend/src/po/assets.ts`（レッスンとコース一覧）と
  `frontend/src/components/PoeAvatar.tsx`（タイトル画面とエラー画面）の2か所
- **`talking` と `blink` の絵が無い**。`neutral` へ寄せてある
  （`PO_FALLBACK`）。まばたきの動きは実装済みなので、絵を置けば効く
- **ポーの絵と部品が2系統ある**。`public/poe/` ＋ `PoeAvatar` と、
  `public/assets/po/` ＋ `PoAvatar`。同じ6枚を2か所に置いている。
  正式画像へ差し替えるときに、片方だけ直すと画面によって別の絵になる
  （食い違いは `frontend/tests/poeAssets.test.ts` が見張る）
- **完了時アンケートの画面が無い**。API（`POST /api/lessons/{id}/survey/`）と
  モデルは残っているが、成果物ファーストへ作り直したときに画面が落ちた。
  下の「2 → 3」の判定に **有料テストの申込率** があるので、
  これが無いと判定できない（後述）

人が用意しないと進まないもの。

- AIプロバイダの鍵、SMTPの接続情報、置き場所とドメイン
- 規約の運営者情報（`frontend/src/content/legal.ts` の `OPERATOR`）
- 管理画面の露出方針、DBのバックアップ、`prune_data` の定期実行

## フェーズ判定のチェックポイント

| 判定 | 次フェーズへ進む条件 |
| --- | --- |
| 1 → 2 | 対面ハンズオンで、参加者の過半数が自力で1つ成果物を完成できた |
| 2 → 3 | β利用者が7日以内にAIを再利用した割合、および有料テストの申込率が想定を満たす |
| 3 → 4 | 個人学習プランの完了率と継続率が、汎用レッスンのみの場合を上回る |
| 4 → 5 | 個人向けの継続率とベンダー別コースの購入率が安定する |
| 5 → 6 | 法人研修の受注が継続し、導入支援の引き合いが発生する |

### 「2 → 3」を判定するために足りないもの

判定条件の2つを、いま測れるかどうか。

| 測るもの | 測れるか | 元にするもの |
| --- | :---: | --- |
| 7日以内にAIを再利用した割合 | ○ | `LearningSession` と `LearningEvent` の日時 |
| 有料テストの申込率 | **×** | 完了時アンケート（画面が無い） |

アンケートの画面を戻すか、別の方法（メールで聞く、対面で聞く）を決めないと、
フェーズ2の判定が片方しかできない。クローズドベータを始める前に決めておく。
