## フェーズ2：初心者向けMVP（2〜6か月） ← 本リポジトリの現在地

- Webアプリ
- 20〜30レッスン
- アプリ内AI
- 改善前後の比較
- 学習記録
- 無料β版
- 有料テスト

**重要**: 初期リリースでは、OpenAI / Google / Anthropic の詳細コースは作らない。
すべてのAIに共通する使い方と考え方に集中する。

**最初の実装対象**: `specs/001-handson-lesson-mvp/` — レッスン1本（文章を分かりやすくする）と
AIチューターの通し体験。

### MVPの完成条件

以下まで動けば、最初の実証実験に使える。

- [x] キャラクター1体 — ポー（`PoeAvatar`）
- [x] 表情6枚 — `frontend/public/poe/*.svg`（**仮画像**。正式画像に差し替える）
- [x] 吹き出し — `PoeAvatar` の `aria-live="polite"`
- [x] 1つのレッスン — `rewrite_text`（当初9ステップ。現在は成果物ファーストの19ステップ、教材は9本）
- [x] 穴埋め入力 — `FillInForm`（誰向け・どんな表現・どれくらいの長さ）
- [x] AI実行 — `POST /api/lessons/rewrite-text/generate/`
- [x] 1回の改善 — `ImprovementSelector` → `IMPROVE_INPUT`
- [x] 自分の文章で再実行 — `RealTaskInput` → `REAL_TASK`
- [x] 完了画面 — `CompletionView`（celebrate＋アンケート4問）
- [x] 操作ログ — `POST /api/learning-events/`（本文は送らない）

**残っているのは正式なポー画像の差し替えのみ**。仮画像のままでも通しで動く。
差し替え口は `PoeAvatar.POE_IMAGE_EXT` の1か所。

Live2D / 音声 / 口パク / 3D / 複数キャラクターは不要。
最初は「キャラクターがかわいいか」よりも、
**初心者が次に何をすればよいか迷わないか** を検証するのが優先。

## フェーズ判定のチェックポイント

| 判定 | 次フェーズへ進む条件 |
| --- | --- |
| 1 → 2 | 対面ハンズオンで、参加者の過半数が自力で1つ成果物を完成できた |
| 2 → 3 | β利用者が7日以内にAIを再利用した割合、および有料テストの申込率が想定を満たす |
| 3 → 4 | 個人学習プランの完了率と継続率が、汎用レッスンのみの場合を上回る |
| 4 → 5 | 個人向けの継続率とベンダー別コースの購入率が安定する |
| 5 → 6 | 法人研修の受注が継続し、導入支援の引き合いが発生する |
