# 画像レッスンで使う絵の一覧

「AIで画像をつくる」の Lesson 1〜4 は、**その場で生成しない**。
先に作った絵を選んで見せる。実行時の費用がゼロになり、
公開日に費用が読めない状態を避けられる。

学びは減らない。このレッスンで身につけるのは
「言葉を足すと絵が変わる」ことで、**変わった絵が実際に見えれば伝わる**。
その絵を、その場で作るか先に作っておくかは、学びの側から見れば同じ。

本物の生成が要るのは Lesson 5（自分のイメージを画像にする）だけ。
題材が利用者自身なので、先に作っておけない。ここは当面
近日公開のままにする。

## 作るもの：20枚

テーマ4 × 雰囲気5。

| | テーマ | 英語の手がかり |
|---|---|---|
| A | カフェ | a cozy cafe interior |
| B | オフィス | a modern office workspace |
| C | 商品（コーヒーカップ） | a coffee cup on a table |
| D | 旅行（海辺の町） | a seaside town street |

| | 雰囲気 | 足す言葉 |
|---|---|---|
| 1 | ふつう | （何も足さない。これが「最初の1枚」） |
| 2 | 明るく開放的 | bright, airy, lots of natural light |
| 3 | 落ち着いた | calm, muted colors, soft lighting |
| 4 | かわいい | cute, pastel colors, rounded shapes |
| 5 | 高級感 | elegant, refined, deep tones |

### ファイル名

```
public/assets/lessons/images/<テーマ>-<雰囲気>.webp

例）cafe-plain.webp / cafe-bright.webp / cafe-calm.webp
    cafe-cute.webp  / cafe-elegant.webp
```

| テーマ | 名前 |
|---|---|
| カフェ | `cafe` |
| オフィス | `office` |
| 商品 | `cup` |
| 旅行 | `town` |

| 雰囲気 | 名前 |
|---|---|
| ふつう | `plain` |
| 明るく開放的 | `bright` |
| 落ち着いた | `calm` |
| かわいい | `cute` |
| 高級感 | `elegant` |

### 作るときの決まり

- **同じ題材で、雰囲気だけを変える。** 構図や被写体まで変わると、
  「雰囲気を足したから変わった」ことが伝わらない。同じ場所を撮り直した
  ように見えるのが理想
- 大きさは **1024×768（4:3）** でそろえる。1枚だけ縦横比が違うと、
  並べたときに変わったのが雰囲気ではなく形に見える
- 人の顔を大きく写さない。実在の人物に見えるものは避ける
- 文字を入れない。読める文字が入ると、それが主役になる
- webp で書き出す。1枚 200KB 以下を目安に

### 権利について

生成に使ったツールの利用規約で、**商用利用と再配布が許されているか**を
確認すること。ここに置く絵は、アプリの一部として配られる。
「生成物の権利は利用者に帰属する」と明記されているツールを使う。

## Lesson 2・3・4 の絵

Lesson 1（雰囲気）が通ってから決める。同じやり方で、

- Lesson 2（構図）… テーマ1つ × 構図5
- Lesson 3（テイスト）… テーマ1つ × 調子5
- Lesson 4（SNS用）… 用途2 × 縦横2

くらいの規模になる見込み。**先に全部作らない。**
Lesson 1 を1本通すと、足りない部品が必ず出る。そこで作りが変われば、
先に作った絵は作り直しになる。

## 置いたあとにすること

絵を `public/assets/lessons/images/` へ置いたら、教材データ側で
`make_images` コースの Lesson 1 を `available` に変える。
画面の実装（選ぶ → 絵が変わる → 見比べる）は、絵が揃った時点で作る。
