## 1. 事業構想

本事業は、AIを使いたいものの、何に使えばよいか分からない個人に対して、
実際にAIを操作するハンズオン形式で最初の成功体験を提供することから開始する。

将来的には、個人ごとの学習教材生成、AIサービス別の専門コース、AIビジネス情報、
法人研修、業務へのAI導入支援までを一体化する。

最終的に目指すのは、次の一連の流れを提供できるプラットフォームである。

```
AIを知る
  → 実際に使う
    → 自分に必要な内容を学ぶ
      → 特定のAIを使いこなす
        → 仕事や事業へ導入する
```

---

## 2. 事業コンセプト

AIで何ができるか分からない人が、実際に触りながら自分に合った使い道を発見し、
必要な知識を学び、仕事や事業へ活用できるようになるプラットフォーム。

- 初期段階では、AI初心者向けのハンズオン学習を中心とする
- その後、ユーザーの目的・職業・AI経験・使用ツールに合わせて、個人専用の教材と学習プランを生成する
- さらに、OpenAI / Google / Anthropic などのAIサービス別コース、AIビジネス情報、
  法人研修、AI導入支援へ展開する

---

## 3. サービス全体像

本サービスを、将来的に以下の5領域で構成する。

### 3.1 AI Hands-on — 初期MVPの対象領域

AIを使いたいが、何をすればよいか分からない初心者向けのハンズオン学習。

主な機能:

- AI活用診断
- おすすめ用途の提案
- 穴埋め式のAI操作
- AI回答の改善
- 実際の課題への応用
- 学習進捗
- AI活用レベル診断

**初期MVPでは、この領域に集中する。**

### 3.2 Personal Learning

ユーザー一人ひとりの目的に合わせて、個人用の教材と学習コースを作成する機能。

ユーザーが入力する希望:

| 項目 | 例 |
| --- | --- |
| AIで何をできるようになりたいか | 会議の議事録を自動でまとめたい |
| 仕事や生活で困っていること | 報告書の作成に時間がかかる |
| 現在のAI経験 | ChatGPTを数回使ったことがある |
| 使える時間 | 1日15分 |
| 興味のある分野 | 資料作成・データ整理 |
| 使用したいAIサービス | ChatGPT / Gemini / Claude |
| 目標とするレベル | 業務で毎日使える |

入力内容を基に、AIが個人用の学習計画を作成する。

生成される内容:

- 学習ゴール
- 推奨コース
- 学習順序
- 1日ごとの課題
- ハンズオン演習
- 理解度確認
- 復習問題
- 実務・日常への応用課題
- 次に学ぶべき内容

**将来的な拡張**: ユーザーが自分の資料（PDF / Webページ / 社内マニュアル / 講義資料 /
書籍のメモ / 自分の業務手順 / 学びたいテーマの文章）を追加し、それを基に教材を作れるようにする。

ただし、初心者に完全な自由入力を求めるのではなく、最初は質問形式で目的を整理する。

### 3.3 AI Platform Tracks

AIに共通する考え方を学んだ後、各AIサービスを個別に使いこなすための専門コースを提供する。

#### OpenAI Track

ChatGPTの基本 / モデルの使い分け / Web検索 / Deep Research / ファイル分析 /
画像生成 / プロジェクト機能 / カスタムGPT / エージェント・自動化 /
OpenAI APIの概要 / 仕事別の活用方法

#### Google AI Track

Geminiの基本 / Google Workspaceとの連携（Gmail・Docs・Sheets・Slides・Drive） /
NotebookLM / Google Workspaceの自動化 / Google Cloud・Vertex AIの入門 /
企業利用における権限・データ管理

#### Anthropic Track

Claudeの基本 / 長文・資料分析 / Projects / Artifacts / Web検索・調査 /
Claude Code / MCP / 業務フローへの組み込み / Anthropic APIの概要 /
安全性・企業利用の考え方

#### コース設計方針

単なる機能説明ではなく、以下の順序とする。

1. 何に使えるか
2. 実際に操作する
3. 他サービスとの違いを理解する
4. 自分の課題に利用する
5. 複数のAIを使い分ける

各社のUIや機能は変化しやすいため、**AIに共通する基礎** と
**サービス固有の操作方法** を分けて管理する。

### 3.4 AI Business Insights

AIの使い方だけでなく、AIが仕事・企業・産業・ビジネスに与える影響を学べる情報領域を設ける。
単なるAIニュース一覧ではなく、初心者や非IT人材でも理解できる形に整理する。

主な内容:

- OpenAI / Google / Anthropic などの重要アップデート
- 新しいAIサービス、AI導入事例、業界別のAI活用
- AIによって変わる仕事、AI関連のビジネスモデル、AIスタートアップ
- 企業のAI戦略、AI関連の法規制・ガバナンス、AIセキュリティ
- AI導入の成功・失敗事例、AIを利用した新規事業、AI人材・キャリア情報

**情報の提供方法** — 一つのニュースについて、以下をまとめる。

1. 何が起きたか
2. 初心者向けの説明
3. なぜ重要か
4. 個人の仕事にどう関係するか
5. 企業や事業にどう影響するか
6. 実際に試すべきこと
7. 関連するハンズオンコース

これにより、ニュースを読むだけではなく、学習と実践につなげる。

> 例: 「Googleが新しいAI機能を発表した」で終わらせず、
> この機能により Google Sheets の分析作業がどう変わるか、実際にどのように使うか、
> どの企業や職種に向いているか、まで説明し、関連する演習へ誘導する。

### 3.5 AI Adoption Services

個人向けサービスで得た教材・学習データ・初心者向けの知見を活用し、
将来的に法人向けのAI導入支援を行う。

提供サービス:

- AI初心者向け研修 / 全社員向けAI基礎研修 / 部門別ハンズオン研修 / 経営層向けAI研修
- AIスキル診断 / AI利用ガイドライン作成
- 業務ヒアリング / AI活用ユースケースの発見 / PoC設計 / AIツール選定
- AIワークフロー構築 / Google Workspaceへの AI導入 /
  OpenAI・Anthropic を利用した業務システム / AIエージェント・自動化の開発
- 導入後の定着支援

導入支援の流れ:

```
1. AI基礎研修
2. 社員のAIスキル診断
3. 業務上の課題収集
4. AI活用候補の整理
5. 小規模ハンズオン
6. PoC
7. 本格導入
8. 利用状況の確認
9. 追加研修・改善
```

研修だけで終了せず、実際の業務導入と開発までつなげる。

## 6. 個人向けサービスの役割

個人向けサービスは、単独で収益を上げるだけでなく、
将来の法人事業に必要な知見を蓄積する役割を持つ。

蓄積できる情報:

- 初心者が理解できない言葉
- AI利用を始められない理由
- よく使われる用途
- 継続利用につながる課題
- AIサービスごとのつまずき
- 学習後に起きる行動変化
- 職種ごとのAI活用パターン
- AI導入時に必要なサポート

個人向け事業と法人向け事業を別々に考えるのではなく、次の循環を作る。

```
個人ユーザーから学習データを得る
  → 教材と研修を改善する
    → 法人研修へ展開する
      → 企業の実務課題を学ぶ
        → 個人向け教材へ反映する
```

## 7. MVPで変えないこと

将来構想を広げても、初期MVPの対象と目的は変えない。

**初期ターゲット**: AIに興味はあるが、何に使えばよいか分からない日本の会社員。

**MVPの提供価値**: 自分に合ったAIの使い道を見つけ、実際に一つ使ってみる。

**MVPで検証すること**:

1. AIの使い道を発見できるか
2. 一人でAIを操作できるか
3. 自分の成果物を完成できるか
4. 7日以内にもう一度AIを使うか
5. 次の内容も学びたいと思うか
6. 有料で利用するか

個人教材、ベンダー別コース、AIビジネス情報、法人研修、AI導入支援は、
すべて初期の学習体験が成立した後に追加する。

## 9. 事業の強み

本事業では、以下の経験を一つのサービスに統合できる。

ソフトウェア開発 / AIツールの実利用 / 非IT人材への説明 / ハンズオン研修 /
プロジェクトマネジメント / 企業運営 / 海外事業 / SaaS事業 / AI導入・業務改善 /
日本と東南アジアでの展開

一般的な教育事業者は教材に強くても、企業へのAI導入やシステム開発まで対応できない場合がある。
一方、システム開発会社は技術に強くても、AI初心者がどこで止まるかを理解した教育体験を持たない場合がある。

本事業では

```
初心者教育 × ハンズオン学習 × AIサービスの理解 × 企業導入 × システム開発
```

を一貫して提供できることを、将来的な差別化要素とする。

## 10. 実行上の原則

> 将来像は広げるが、最初のプロダクトは広げない。

その後に個人教材生成、ベンダー別コース、AIビジネス情報を追加する。
