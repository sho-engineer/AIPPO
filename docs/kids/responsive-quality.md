# Kids 縦横レスポンシブ受入条件（AIPPO-016）

幅のみでdesktopへ切り替えず、横向きの利用可能な高さを優先する。公式Po、中央ロゴ、既存の課題・採点・記録・安全説明は維持。回転で再読み込み・状態初期化・記録の追加を行わない。

## 対象

- スマホ縦320×568 / 375×667 / 390×844 / 430×932と各横向き。
- タブレット768×1024 / 1024×768。
- Home初回/再訪、全3モード、5マップ、25課題、5つの知識・実践テスト、結果・スタンプ、親まとめ、設定、日常課題の採用/修正/保留。
- 選択中・結果・親まとめ・資料比較・設定の回転。保存エラーの警告併存。

## 検査

子の主画面は全体スクロールなしで主要操作が画面内・クリック可能。横はみ出し、最小高さによる切れを許容しない。成人向け親記録/設定/長い補足はスクロール可能とし、全内容と退出操作に到達できることを検査する。子の本文を無断に削ったり、正答条件・記録を変えたりしない。

日常課題は選んだ条件と閉じる操作が本文スクロールの外に残り、本文に少なくとも44pxの表示領域を確保する。資料の対象・日時・発信元・更新日時、複数選択・none、判断ルール・保存不能告知は維持。保存不能の告知を閉じて隠すことを解決策にしない。

既存24ケースを削らず検査viewportを拡張し、回転・全課題・故障注入を追加する。早期停止は失敗時のみで、その実行で残った未実行をPassedにしない。全成功時は全ケース完了が必須。

## ペルソナと限界

全24模擬ペルソナをID別に批判・反論・再評価し、採用/見送り理由と未検証を記録する。3人の実際の担当エージェントによる模擬評価であり、24人の実参加者ではない。

ChromiumのCSS viewport・mobile emulationは実iPhone Safari、セーフエリア実機、ソフトウェアキーボード、ブラウザUIの出入り、読解・楽しさ・教育効果の保証ではない。これらは別途Not Testedとする。

本書は受入条件であり、実施前の検査をPassedとするものではない。結果はPR/CIと最終検証報告・共通台帳へ記録する。
