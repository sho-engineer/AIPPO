# AIPPO-013：24ペルソナからの改善判断

対象：Kids β。2026-10-15。前回の採否記録は変更せず、本変更の判断を追記する。
ペルソナは子ども12・保護者12の仮想レビュー。実利用者の観察・学習効果の証明ではない。

## 採否と反論

| 論点 | 判断・実装 | 反論を受けた境界 |
|---|---|---|
| F01 途中で閉じると消える | 未完了は最初から、と短く事前表示。即座に閉じられる | 下書き保存・退出承認は増設しない。完了記録との混同を防ぐ |
| F02 物語が先に終わる | 世界4から5へ橋渡しするPoの台詞 | 未実装の章や実際にない冒険を約束しない |
| F03 贈り物の完成を約束 | 色を考える準備と明記 | 選択だけでカードを制作・印刷したとは表示しない |
| F04 常にAIを修正する | 一致・不一致・不明を比較し、採用・修正・保留を判断 | 情報源の書換えを正解にしない。不明は保留。旧履歴の評価を昇格しない |
| F05 練習文の外部利用 | 教材用と明示。保護者が公開対象・具体日付に置換 | 自動送信、個人情報入力、実AI契約は追加しない |
| F06 子どもの意向 | 家庭報告で任意の希望・休憩を扱う | 感情スコア・必須回答・継続圧力にはしない |
| F07 安全確認の一律誤答 | 間違えた判断だけ説明し、正しい選択を保持 | 答えの自動選択はしない。読み補助も検証する |
| F08 記録上限が不明 | 家庭30、チャレンジ50、作品50を明記 | 無制限保存・端末同期・JSON復元は未実装 |
| F09 再挑戦が残らない | 初回を保持し、通常課題ごとの直近1回を別保存 | 全試行履歴ではない。回数減少を能力向上に換算しない |
| N-Y01 読み補助が年齢固定 | 自動・表示・非表示を学び方と独立に選択 | 全漢字・音声・読解診断を提供するとは言わない |
| N-O01 同日の最新記録 | 新記録の連番で並べ、初回と直近を区別 | 旧日付のみの記録に時刻を捏造しない |
| N-O02 日付基準が混在 | 新記録にISO時刻・端末の地域設定・現地日付を保存 | 旧UTC/MYT記録を変換しない。日付差を24時間・定着と断定しない |

実装上の追加対策：実践テストのpreviousAssessmentは、新しい保存時に一段だけ保持する。旧データは読み込みだけで書き換えず、作品履歴は50件を維持する。時計が戻っても連番を使い、別タブの保存競合を保護する。

## 完了条件

1. 上記採否を実装へ照合。
2. 一致・不一致・不明、未選択、誤判断、旧履歴保持、初回・直近・時計逆転・保存競合・読み補助を回帰試験。
3. 全単体試験、TypeScript、Lint、Lesson検査、production buildを確認。
4. C01〜C12・P01〜P12の全員に実装後の意見と反論を記録。欠員を平均値で隠さない。
5. 実ブラウザで小画面、新判断フロー、再読込、親の記録を確認し、全CIを通す。
6. 検証済みコミットをマージし、台帳と成果物へ証跡を保存。

検査結果・PR・採否の追加修正はMission Registryと最終QA報告に記録する。本書自体は全検査のPassed宣言ではない。

## 実装後レビューの採否

全24名を2巡、IDごとに批判・反論・未検証を記録した。C02/C09のF05残存（完了画面から教材文をコピーする説明）、C12のF03同類（形選びだけで完成絵を約束する表現）を最小修正し再確認した。

P07/P12の「日時の技術情報が長い」はP2改善候補として残す。今回は旧・新記録の基準を隠さず、折返し・スクロールとブラウザ検査を優先する。初心者への認知負荷は未観察であり、短縮表示を入れたことにはしない。作品制作・同期・復元・順位・自由AI会話は、願望だけで今回へ追加しない。

## 残す製品制約

同ブラウザ1人分、複数端末同期なし、復元UIなし、自由な外部AI会話なし。実親子の理解・楽しさ・再訪・未見題材への転用・支払意向はNot Tested。教材内の判断記録や仮想ペルソナの評価を、日常で自立利用できた証拠へ置き換えない。公開Lessonの状態と公式Po素材は変更しない。
