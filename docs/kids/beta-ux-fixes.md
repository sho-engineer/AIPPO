# AIPPO-015：βレビューで指摘した3点の修正

対象：Kids β、AIPPO-014の公開前レビュー。実親子の教育効果ではなく、表示・読みやすさ・次の行動の整合を改善する。

## 変更と受入条件

1. 基礎冒険の課題進捗と、日常の練習記録を別のラベルで表示する。50件までの記録数を累計・ユニーク課題数・能力・共通成長率と呼ばない。変化しない3点の装飾を除き、QUEST番号と実践テストの工程表示は保持する。
2. 日常課題では選んだ条件を本文スクロールの外で確認できるようにする。判断に必要な子ども向け説明は残し、親向け補足を折りたたむ。資料の対象・日時・発信元・更新日時、複数選択、採用/修正/保留の採点と保存証拠は変えない。小画面で条件と閉じる操作が到達可能であることを検査する。
3. 親の「最近の記録と次の一歩」を先頭に置き、最終クリアから任意の家庭の目的を選べるようにする。達成記録への副導線、途中で閉じる自由、AIを使わない選択を保持する。家庭実施・外部送信・支払いを進級条件にしない。

## 品質確認

新規DOM回帰検査と既存Kids回帰、全フロントエンド、TypeScript、Lint、Lesson Spec、production build、既存CI各ジョブを検証する。小画面の既存20件を維持し、進捗・親要約・最終テストからの両導線をブラウザで追加検査する。

全24模擬ペルソナの個別批判・反論を別報告に保存する。画面が操作できることを、読解・楽しさ・教育効果の検証へ置き換えない。実親子と本番iOS実機の観察は別ゲート。

検査の結果はPR/CIと共通Mission Registryへ記録する。本書は検査実行前の受入条件であり、Passed宣言ではない。
